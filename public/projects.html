IoT Smart Battery Health (SOH) & Life Prediction System

Working Bench Prototype
Current & Voltage Sensing
Temperature Monitoring

A hands-on IoT prototype designed to track Lithium-ion battery metrics including voltage, current, and temperature. Using an ESP32 microcontroller with an INA219 sensor and DS18B20 thermal probe, the system estimates State of Health (SOH) through Coulomb counting and provides threshold-based alerts to prevent over-discharge and high-temperature stress.

PROTOTYPE HIGHLIGHTS & SENSORS
  • • Sensor Interfacing: Wired an INA219 current/voltage transducer over I2C alongside a DS18B20 digital thermal probe to log real-time battery status.
  • • Capacity & SOH Estimation: Implemented basic Coulomb counting and discharge tracking to estimate capacity degradation across charge cycles.
  • • Safety Alerts: Configured warning thresholds for over-temperature, low-voltage cutoff, and excessive current draws.
  • • AI-Assisted Code Development: Utilized AI coding tools for sensor library configuration, math routines, and serial visualization.

Motor Health & Vibration Anomaly Detection Prototype

Working Experimental Rig
Accelerometer Telemetry
Anomaly Threshold Flags

A practical condition monitoring prototype built to study vibration patterns in small motors. Interfacing an ESP32 microcontroller with an accelerometer, the prototype reads continuous motion data to identify unusual vibration spikes and compare them against basic operating thresholds.

PROTOTYPE HIGHLIGHTS & SENSORS
  • • Vibration Sensing: Connected an accelerometer to capture continuous acceleration readings along multiple axes during motor run cycles.
  • • Threshold Anomaly Detection: Evaluated root-mean-square (RMS) vibration levels to flag abnormal shaking or motor imbalance.
  • • Data Logging: Streamed telemetry over serial connection for real-time visualization and diagnostic logging.
  • • AI-Assisted Code Development: Applied AI pair programming for signal smoothing algorithms and threshold alerting routines.
